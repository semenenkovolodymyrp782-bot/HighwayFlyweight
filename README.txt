ПРОЄКТ: ІМІТАЦІЯ РУХУ МАШИН АВТОБАНОМ (FLYWEIGHT)

ВИМОГИ:
- Visual Studio 2022
- .NET Framework 4.8
- Windows Forms

ЯК ВІДКРИТИ:
1. Розпакуйте архів.
2. Відкрийте HighwayFlyweight.csproj у Visual Studio.
3. Якщо Visual Studio запропонує встановити .NET Framework 4.8 Developer Pack, встановіть його.
4. Натисніть F5.

ДЕ ІНТЕРФЕЙС:
MainForm.cs — логіка кнопок, анімація та малювання.
MainForm.Designer.cs — усі елементи форми, які можна редагувати у візуальному конструкторі.
Щоб відкрити конструктор: відкрийте MainForm.cs і натисніть Shift+F7 або виберіть View Designer.

СТРУКТУРА:
Models/Car.cs — окремий автомобіль, його координати та швидкість.
Flyweights/CarFlyweight.cs — спільний об'єкт із характеристиками типу машини.
Flyweights/CarFactory.cs — фабрика, що зберігає та повторно використовує Flyweight.

ЯК ПОКАЗАТИ FLYWEIGHT:
1. Додайте кілька легкових автомобілів.
2. Лічильник «ОБ'ЄКТІВ FLYWEIGHT» залишиться рівним 1.
3. Додайте вантажівку — лічильник стане 2.
4. Додайте автобус — лічильник стане 3.
Тобто багато автомобілів одного типу використовують один спільний об'єкт Flyweight.
